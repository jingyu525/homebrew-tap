# jingyu525/homebrew-tap

Personal Homebrew tap for [jingyu525](https://github.com/jingyu525)'s
command-line tools.

## Install

```bash
brew install jingyu525/tap/free-kiro
```

## Available formulae

| Formula | Description | Source |
|---|---|---|
| [`free-kiro`](Formula/free-kiro.rb) | Spec-driven development workflow CLI | [jingyu525/free-kiro](https://github.com/jingyu525/free-kiro) |

## Maintenance

The Formula files are auto-generated by [GoReleaser](https://goreleaser.com/)
on every GitHub release of the source repo. Do not edit by hand —
your changes will be overwritten on the next release.

To bootstrap a new tap (or to recover after a botched release):

1. Create the repo on GitHub
2. Create `Formula/<binary>.rb` with a placeholder `sha256`
3. On the next tagged release of the source repo, GoReleaser will
   rewrite the Formula with the correct URL + sha256
